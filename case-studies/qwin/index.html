01 / Context

A real problem.
A focused product.

Listing a second-hand product often requires too many repeated steps: taking photos, writing descriptions, selecting categories and repeating the process for different channels.
Approach

Designed around the user journey.

I am building a single, responsive Flutter journey for creating and exploring listings, using category-aware forms, image workflows, user profiles, search and marketplace API integrations where supported.

Role & ownership: I worked on the product direction, interface decisions, Flutter implementation, cloud integrations, testing and release workflow. The portfolio describes my own product work, not a third-party client engagement.
