# Journal Studio — бесплатный локальный режим

Статическая редакция, размещённая в том же GitHub Pages репозитории, что и mynw.app.

Адрес: https://mynw.app/journalstudio/

- Отсутствует в главном меню и sitemap.
- `noindex,nofollow` препятствует обычной индексации, но НЕ является контролем доступа.
- IndexedDB хранит статьи и фотографии только в браузере текущего устройства.
- Для предотвращения потерь обязательно экспортируйте резервные копии JSON.
- Фото обрабатываются локально и уменьшаются до 1400px WebP.
- Создание статей, блоков, авторов, редакционных статусов, предпросмотр и экспорт JSON/HTML/Instagram-текста.
- Выгрузка материалов вручную. Реальные приглашения, AI API и автопубликации не подключены.
- Не храните конфиденциальные материалы: URL и исходный код доступны публично.

Промышленная версия может повторно использовать прежний серверный клиент `JournalStudio_mynw_web_v0_2`, когда будет подключена авторизация и backend. Секреты API не размещать на GitHub Pages.
