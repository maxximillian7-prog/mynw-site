## Source of truth

- `pr_categories.telegram_hashtag` хранит закреплённые значения.
- `pr_telegram_hashtag(category)` разрешает родительскую рубрику рекурсивно.
- `pr_build_telegram_post(item_id)` формирует фактический текст с заголовком, лидом, содержанием, ссылкой на первоисточник и тематическим хештегом **в конце**. Ограничение 4000 символов оставляет резерв относительно Telegram Bot API 4096.
- `pr_build_telegram_caption(item_id)` формирует короткую версию для подписи к фото, максимум 1024 символа, сохраняя ссылку на источник и хештег в конце.
- `pr_posts.prepared_text`, `pr_posts.prepared_caption`, `pr_posts.category_hashtag` — зафиксированные тексты будущей отправки. Триггер `pr_posts_prepare_payload` заполняет их при постановке в очередь/планировании; SQL CHECK не допускает отсутствующей или неправильной метки.
- `pr_telegram_delivery_queue` — выборка кандидатов для будущего бота, включая разрешённую фотографию. Пока назначения main, afisha, forum, moderation отключены: **ничего не публиковать**.
- `pr_telegram_editor_previews` — форматируемый предпросмотр (текст и caption).
- В Journal Studio /portugal/ редактор видит метку в списке и предпросмотре и может копировать точно рассчитанный сервером текст только после сохранения правок.

## Будущий Telegram sender (не включён)

Отправлять только запись с пройденной проверкой одобрения. Не собирать текст из отдельных полей и не просить модель сгенерировать хештег заново. Для текстового поста использовать `prepared_text`. Для поста с картинкой, если `prepared_text` укладывается в Telegram Photo caption, можно отправить фото вместе с `prepared_caption`; иначе отправить фото с `prepared_caption` и полную статью отдельным `sendMessage` с `prepared_text`, не нарушая ограничений Telegram. Ссылки на недокументальные AI-обложки и авторство обозначать явно. Не прикладывать изображения с неподтверждёнными правами. Перед фактической отправкой ещё раз проверить актуальность события, статус редакционного одобрения и отсутствие дубликата. Нельзя автоматически включать Telegram-назначение, пока оператор не настроил бота и канал.
